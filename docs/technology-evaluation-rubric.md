# Technology Evaluation Rubric

## Purpose

This rubric provides a standardized, objective framework for evaluating educational technology tools before procurement. All technology acquisitions must be assessed against these criteria to ensure alignment with institutional goals, compliance requirements, and stakeholder needs.

## Evaluation Categories and Weights

| Category | Weight | Description |
|----------|--------|-------------|
| Pedagogical Alignment | 25% | How well the tool supports teaching and learning goals |
| Accessibility | 20% | Compliance with accessibility standards and universal design |
| Privacy and Security | 20% | Data protection, compliance, and security posture |
| Usability | 15% | Ease of use for educators, students, and administrators |
| Cost and Sustainability | 10% | Total cost of ownership and long-term viability |
| Integration and Scalability | 10% | Compatibility with existing systems and growth capacity |

## Scoring Scale

| Score | Rating | Description |
|-------|--------|-------------|
| 4 | Excellent | Fully meets or exceeds all criteria; best-in-class |
| 3 | Good | Meets most criteria with minor gaps; above average |
| 2 | Adequate | Meets minimum requirements; some improvement needed |
| 1 | Poor | Significant gaps; does not meet key requirements |
| 0 | Unacceptable | Fails to meet minimum standards; disqualifying |

## Detailed Evaluation Criteria

### 1. Pedagogical Alignment (25%)

| Criterion | 4 - Excellent | 3 - Good | 2 - Adequate | 1 - Poor |
|-----------|--------------|----------|--------------|----------|
| Learning objective support | Directly enables multiple learning objectives with evidence of efficacy | Supports key learning objectives | Indirectly supports some objectives | Minimal connection to learning goals |
| Active learning | Promotes student engagement, collaboration, and creation | Supports interactive activities | Primarily content delivery with some interaction | Passive consumption only |
| Assessment integration | Built-in formative and summative assessment with analytics | Assessment capabilities with basic reporting | Limited assessment features | No assessment capability |
| Differentiation | Adaptive learning paths, multiple modalities, personalization | Some differentiation options | Limited customization | One-size-fits-all approach |
| Research evidence | Peer-reviewed studies demonstrating learning gains | Case studies and pilot data available | Vendor-provided efficacy claims | No evidence of effectiveness |

### 2. Accessibility (20%)

| Criterion | 4 - Excellent | 3 - Good | 2 - Adequate | 1 - Poor |
|-----------|--------------|----------|--------------|----------|
| WCAG compliance | Full WCAG 2.1 AA conformance with third-party audit | Substantial conformance with documented VPAT | Partial conformance with remediation roadmap | Significant accessibility barriers |
| Screen reader compatibility | Fully compatible with major screen readers | Compatible with most functions | Limited compatibility | Incompatible |
| Keyboard navigation | Full keyboard accessibility | Most functions accessible | Basic navigation only | Requires mouse |
| Captioning and transcription | Auto-captioning with editing, transcript download | Captioning available | Manual caption upload only | No captioning |
| Multilingual support | Multiple languages with localization | Select language options | English only with translation API | No language options |

### 3. Privacy and Security (20%)

| Criterion | 4 - Excellent | 3 - Good | 2 - Adequate | 1 - Poor |
|-----------|--------------|----------|--------------|----------|
| Data handling | Data minimization, encryption at rest and in transit, zero-knowledge options | Strong encryption, clear data practices | Basic encryption, standard practices | Unclear data handling |
| Compliance certifications | SOC 2 Type II, ISO 27001, FERPA attestation | SOC 2 Type I, FERPA compliant | Self-attested compliance | No certifications |
| Data ownership | Institution owns all data, full export capability, deletion on request | Clear data ownership, export available | Shared ownership model | Vendor retains data rights |
| Incident response | Documented plan, <24 hour notification, breach insurance | Response plan with <72 hour notification | Basic notification procedures | No documented plan |

### 4. Usability (15%)

| Criterion | 4 - Excellent | 3 - Good | 2 - Adequate | 1 - Poor |
|-----------|--------------|----------|--------------|----------|
| Learning curve | Intuitive, minimal training required | Brief training sufficient | Moderate training needed | Extensive training required |
| Mobile experience | Native mobile apps with full functionality | Responsive design with most features | Basic mobile access | Desktop only |
| Technical requirements | Works on all modern browsers, low bandwidth | Works on most browsers, moderate bandwidth | Specific browser/OS requirements | High technical requirements |
| Support resources | 24/7 support, extensive documentation, community forum | Business hours support, good documentation | Email support, basic documentation | Limited support |

### 5. Cost and Sustainability (10%)

| Criterion | 4 - Excellent | 3 - Good | 2 - Adequate | 1 - Poor |
|-----------|--------------|----------|--------------|----------|
| Pricing model | Transparent, institutional pricing, no hidden fees | Clear pricing with volume discounts | Standard pricing with some add-on costs | Complex pricing with significant add-ons |
| Total cost of ownership | Low ongoing costs, included updates and support | Moderate ongoing costs | Significant ongoing costs | Escalating costs over time |
| Vendor stability | Established company, strong financials, growing user base | Stable company, adequate funding | Early-stage with funding | Financial concerns |
| Contract flexibility | Month-to-month available, easy cancellation | Annual with 30-day cancellation | Multi-year with early termination fee | Locked-in multi-year with penalties |

### 6. Integration and Scalability (10%)

| Criterion | 4 - Excellent | 3 - Good | 2 - Adequate | 1 - Poor |
|-----------|--------------|----------|--------------|----------|
| LMS integration | LTI 1.3 Advantage, deep integration | LTI 1.1, basic integration | Manual integration possible | No integration capability |
| SSO support | SAML, OAuth 2.0, SCIM provisioning | SAML or OAuth | Basic SSO available | No SSO |
| API availability | Comprehensive REST API with documentation | API for key functions | Limited API | No API |
| Scalability | Proven at scale (>50K users), auto-scaling | Tested at moderate scale | Small-scale deployment only | Scalability concerns |

## Minimum Thresholds

A product must meet these minimum scores to be considered:
- **Privacy and Security:** Minimum score of 2 on all criteria
- **Accessibility:** Minimum score of 2 on WCAG compliance
- **Overall weighted score:** Minimum 2.5 out of 4.0

## Evaluation Process

1. Vendor completes self-assessment using this rubric
2. Evaluation team independently scores using rubric
3. Product demonstration and hands-on testing
4. Pilot program with selected users (minimum 4 weeks)
5. Final scoring with pilot feedback incorporated
6. Recommendation report submitted to Governance Committee
